# 盈進学園東野高等学校

**所在地:** 埼玉県入間市  
**開校:** 1985年4月  
**敷地面積:** 約2万坪（埼玉県内高校最大級）  
**設計:** クリストファー・アレグザンダー + CES（Center for Environmental Structure）  
責任者: [[hosoi-hisae|細井久栄]]
**施工:** フジタ（大手ゼネコン）  
## 概要

クリストファー・アレグザンダーが直接携わった『パタン・ランゲージ』の実装として、**世界最大規模**の事例。1978年の計画開始から1985年の開校まで、施主側責任者・細井久栄とアレグザンダーが、教職員・生徒の参加を得て、400年間変わらぬ建築思想に対抗する試みを実現した。

## 建築的特徴

### 構成要素

| 施設            | 特徴                            |
| ------------- | ----------------------------- |
| **玄関道**       | 80メートル、大谷石の踏み石、板塀（上下が逆の伝統的形式） |
| **広場**        | 砂利敷き、浅間火山砂混合、ザルツブルグ旧市街をモデル    |
| **池**         | 茶畑の窪地をそのまま活用、アヒル14羽が象徴        |
| **カフェテリア**    | グループ・プライバシー確保のブース設計           |
| **大講堂**       | 黒漆喰（石黒氏が1年間住み込みで仕上げ）、シャンデリア   |
| **木造体育館**     | 大口径の木造大構造、戦後初の大規模木造建築         |
| **ホーム・ルーム通り** | 段差のある床、自然採光・通風、家のような教室棟       |

### 木造主体

- 戦後1959年の建築学会「木造禁止」から25年を経て初の大規模木造建築
- 木という素材が与える「くつろぎと落ち着き」を徹底追求
- 日土小学校（松村正恒設計）の訪問が決定的転機

## 設計プロセス

### フェーズ1：利用者参加（パタン・ランゲージ生成）

- 教職員100人以上のインタビュー実施
- **プロジェクト・ランゲージ**の作成：心の奥底の本音から出発
- 単なる「問題解決リスト」ではなく「生命を感じさせるパターン」

### フェーズ2：配置計画（Structure-Preserving）

- 現地で旗竿を用いた実験的配置
- 茶畑の起伏を活かし、窪地は池に
- 「土地の声を聞く」アレグザンダーの手法

### フェーズ3：詳細設計・実装

- 毎週の「おしん会議」（CES・フジタ・教職員による対立的熟考）
- System A（感性）と System B（合理性）の衝突と統合
  - 木造体育館問題：著者の「土下座」による決断
  - 合意形成の日本的課題の露出

## 全体性の実現

### 空間的全体性

- 玄関道（閉じた空間）→ 広場（開放的ノード）→ 建物群（個別ユニット）の階層構造
- 池が「キャンパスの生命の核」として機能
- 四季を通じた自然環境との調和

### 社会的全体性

- グループ・プライバシーの確保（カフェテリア・ブース）
- 利用者参加が設計プロセスを貫く
- 職人精神の尊重（大工・住吉氏、左官・石黒氏）

### 時間的全体性

- 玄関道の「起」と下校の「結」という毎日の儀式性
- 村祭り（文化祭）のような定例行事
- 池の水上ステージでの花火大会

## 課題と学び

### 利用者参加の実態

- **成功要因**: 施主（著者）の揺るがぬビジョン + アレグザンダーの支援手法
- **課題**: 専門家の提案による「参加の阻害」
  - 玄関道の塀：教員・野寺陽彦の「常識外」スケッチをアレグザンダーが採用
  - 教員たちの信頼回復の重要性

### 合意形成の問題

- 日本の民主主義における「ご都合主義」（多数派の変心で決定が翻る）
- 前の決定の尊重が困難
- 「おしん会議」モデル：対立を避けず、互いにぶつかることで統合に至る

### 時間による変容

- 裸足の廃止による「小学校らしさ」の解体
- 設計者の意図との時間的乖離
- 文化の保存と進化の緊張関係

## 後続への影響、現在の評価

### 建築分野

- 当時は大型木造建築は非常識 → 木造校舎への再評価（文部科学省2007年、木材利用学校づくりを推奨）
- 大型木造建築が技術的に困難だった → CLT（Cross Laminated Timber）による高層木造の可能性拡大
- 木造ではなくアルミサッシが強く求められた → サッシ問題：樹脂製・木製サッシの国際的評価向上

### パタン・ランゲージ応用

- 使用者参加型設計は非常識 → まちづくり規範（デザイン・コード）への展開
  - 埼玉県川越一番街、滋賀県長浜市、神奈川県真鶴町、香川県高松丸亀町
- 校内の大きな池 → ビオトープ運動との接続（学校ビオトープの拡大）

### 利用者参加デザインの教訓

- システム A（感性）と System B（合理性）の補完的統合が必須
- 参加型デザインには「参加支援の支援」が重要
- 専門家の役割：利用者の自信を奪わない伴走
