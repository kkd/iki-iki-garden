## 要約

パタン・ランゲージをビジュアルに操作するツール群「Pattern Canvases」を初めて体系化したプレゼン資料（2011年）。**パタン・キャンバスの確認できる最古の初出**。BusinessModelingGeneration（ビジネスモデルキャンバス）に強くインスパイアされた設計。Pattern Canvas と Force Canvas の2種類を提案。

## Pattern Canvas

アレグザンダーのパタンフォーム（Context / Problem / Force / Solution / Consequence）をキャンバス形式に転換したもの。

**フォーム構成:**
```
| Name                                    |
|---------|--------|----------|-----------|
| Context | Problem | Solution | Consequence |
|         | Force  |          |           |
```

**5つの使用モード（Usage × Scene）:**

| Usage | Scene |
|---|---|
| **Solution Driven** | 過去の解決策をパタンとして整理する |
| **Problem Driven** | 直面している問題を解決する |
| **Context Driven** | 曖昧な文脈から問題・フォースを明確化する |
| **Force Driven** | フォースと文脈を明確化し、解決策を導く |
| **Consequence Driven** | 望ましい未来のビジョンから計画する |

「過去（Solution Driven）」「現在（Context/Force/Problem Driven）」「未来（Consequence Driven）」の3時制すべてで使用可能。

## Force Canvas

**Force Canvasとは:** すべてのフォースを同時に解消する良い解決策を探索するツール。Johan GaltungのTranscend Methodに強くインスパイア。Original Idea: Hiroshi Nakano。

**5つの解決タイプ:**
- **Transcendence** — すべてのフォースを一度に解消する解決策
- **Compromise** — 公平だが超越的でない解決策
- **Forces prevailing** — 一部のフォースを犠牲にする解決策
- **Desire prevailing** — Desideを犠牲にする解決策
- **Withdrawal** — 状況から離脱する解決策

Force Canvasの目的は「Transcendence（超越）」に向かうことを可視化すること。
